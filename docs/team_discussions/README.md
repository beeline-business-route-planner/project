# team_discussions — расшифровки внутренних созвонов команды

Автоматические расшифровки (транскрипты) рабочих созвонов команды по разработке решения.
Это "сырое" мышление вслух — куча предложенных, но отвергнутых идей, споров, шуток и
нецензурной лексики. Итоговые (актуальные на сегодня) решения вынесены в `SUMMARY.md` —
читать в первую очередь его, к транскриптам обращаться только за деталями/контекстом
конкретного решения.

## Как читать эти файлы

Каждый PDF — это экспорт "Meeting Summary" с двумя частями:
1. **Summary** (в начале документа) — сокращённая выжимка созвона, сделанная
   автоматическим инструментом транскрибации. Достаточно почитать только её, чтобы понять
   суть встречи.
2. **Transcript** — полная дословная расшифровка, нужна только если непонятен контекст
   решения из summary или требуется найти точную формулировку/цифру.
