# team_discussions — расшифровки внутренних созвонов команды

Автоматические расшифровки (транскрипты) рабочих созвонов команды по разработке решения.
Итоговые, актуальные решения — в `SUMMARY.md`, читать в первую очередь его. К транскриптам
обращаться только за деталями/контекстом конкретного решения (точная формулировка, цифра).

## Как читать эти файлы

Каждый PDF — экспорт "Meeting Summary" с двумя частями:
1. **Summary** (в начале документа) — сокращённая выжимка созвона. Достаточно почитать
   только её, чтобы понять суть встречи.
2. **Transcript** — полная дословная расшифровка, нужна только если непонятен контекст
   решения из summary или требуется найти точную формулировку/цифру.
