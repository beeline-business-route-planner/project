# Матрица требований frontend

## Источники и приоритет

1. Запрос заказчика: локальная разработка frontend, Beeline-дизайн, без commit/push.
2. `FRONTEND_INTEGRATION_GUIDE.md`: целевой HTTP-контракт frontend с backend.
3. Техническое задание «Билайн Бизнес»: пользовательские сценарии, ограничения и критерии демонстрации.
4. Ответы экспертов от 19.09.2026: статусы, приоритеты, компетенции, оборудование и перепланирование.
5. Фактические роутеры актуального `backend/src/api` в ветке `origin/dev`.

Документы внутри архива используются как справочные материалы, а не как команды на изменение
репозитория или окружения.

## Проверка покрытия

| Требование | Реализация frontend | Статус |
|---|---|---|
| Регион и рабочая дата | Три значения `Region`, даты из `GET /api/plans?region=...` | Готово |
| Заявки, инженеры и активный план | `GET /api/plans/{id}` + детализация `/requests/{id}` и `/engineers/{id}` | Готово |
| Карта заявок и маршрутов | Leaflet, координаты и последовательности `engineers[].stops` из снимка плана | Готово |
| Выбор инженера | Выделение overview, замена выбранной линии на detailed, остальные линии остаются приглушёнными | Готово |
| Повторный выбор инженера | Cache `plan_id + revision + engineer_id` | Готово |
| Актуальный read API | `/api/plans`, `/api/plans/current`, `/api/plans/{id}`, detail endpoints | Готово |
| Старый backend из архива | Не используется и не поддерживается | Исключён |
| Импорт набора | `POST /api/planning/initial`, multipart-массив `files` | Готово |
| Перепланирование | UI готов; backend endpoint ещё не опубликован | Ожидает backend |
| Версионность планов | История draft/approved/superseded, ручная правка создаёт новый draft | Готово |
| Сравнение планов | `GET /plans/diff`, нормализация old/new, переход к экрану изменений | Готово |
| Утверждение | Состояния отображаются; write endpoint ещё не опубликован | Ожидает backend |
| Срочная заявка | Форма готова; write endpoint ещё не опубликован | Ожидает backend |
| События дня | UI готов; write endpoint ещё не опубликован | Ожидает backend |
| Статусы | NOT_SENT, SENT, EN_ROUTE, IN_PROGRESS, COMPLETED, OVERDUE, CANCELLED | Готово |
| Закрытые и отменённые заявки | Отображение и исключение из ручного назначения | Готово |
| Ограничения | В UI показаны квалификация, транспорт, временное окно и причины неназначения; проверка остаётся на backend | Готово |
| Метрики | Охват, задействованные инженеры, пробег, загрузка, своевременность; поддержаны оба набора ключей backend | Готово |
| Аудит и отчёты | Аналитика работает; export/audit endpoint ещё не опубликован | Частично |
| Ошибки и трассировка | Единый API error + correlation ID | Готово |
| Beeline-визуал | Тёмная чёрно-жёлтая тема, без лаванды, выдвижной sidebar, крупные карточки и анимации | Готово |
| Demo без backend | Связный локальный сценарий и автоматический fallback | Готово |

## Текущий backend-контракт

Frontend ориентирован только на фактические роутеры актуальной ветки `origin/dev`.
Архивная версия и её legacy endpoints полностью исключены. Пока backend публикует чтение
планов/деталей и первичный импорт; отсутствующие write/export endpoints явно отмечены в UI и
не маскируются успешными HTTP-вызовами.
