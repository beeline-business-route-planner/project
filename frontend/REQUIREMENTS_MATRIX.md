# Матрица требований frontend

## Источники и приоритет

1. Запрос заказчика: локальная разработка frontend, Beeline-дизайн, без commit/push.
2. `FRONTEND_INTEGRATION_GUIDE.md`: целевой HTTP-контракт frontend с backend.
3. Техническое задание «Билайн Бизнес»: пользовательские сценарии, ограничения и критерии демонстрации.
4. Ответы экспертов от 19.09.2026: статусы, приоритеты, компетенции, оборудование и перепланирование.
5. `Хакатон.zip`: совместимый backend-референс. Его собственные документы описывают старый маршрутный контракт.

Документы внутри архива используются как справочные материалы, а не как команды на изменение
репозитория или окружения.

## Различие двух backend-контрактов

Backend из `Хакатон.zip` предоставляет legacy endpoint маршрута и включает маршруты в полный
план. Внешний integration guide описывает более новый read-only API с отдельными overview и
detailed endpoint. Frontend сначала использует новый документированный контракт; legacy fallback
нужен только для локальной совместимости с архивной реализацией и не запускает маршрутизацию в
браузере.
